# Logos

All files are SVG with text outlined (no fonts needed). The clover is drawn with round-capped strokes. Generated by `scripts/build_clover.py`.

Inks: `-ink` espresso `#4B2E20`, `-cream` `#F5EDE0`, `-wine` `#5C2230`. Descriptor: `-en-` "coffee · wine · flowers", `-sq-` "kafe · verë · lule".

- `clover-lockup-stacked-{en,sq}-{ink,cream,wine}.svg`: primary lockup.
- `clover-lockup-horizontal-{en,sq}-{ink,cream,wine}.svg`: for narrow spaces.
- `clover-badge-{en,sq}-{cream,espresso,kraft}.svg`: round sign with its own background.
- `clover-mark-{ink,cream,wine}.svg`: the clover alone.
- `clover-wordmark-{ink,cream,wine}.svg`: "Clover" alone.
- `clover-avatar-{cream,espresso,kraft}.svg`: 400×400 profile images.
