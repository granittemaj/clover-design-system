# Logos

All text is outlined, so the files need no fonts. Each file has fixed colours, named in its suffix.

- `-day`: full colour for light grounds. Leaves peony `#B02A5A`, matcha `#4A671B`, wine `#5E1A33`, honey `#C08A1E`; stem and word ink `#1E2A1F`.
- `-evening`: full colour for the evening ground and for wine. Leaves `#F28DB0`, `#A9C56B`, `#C25A7C`, `#EDB54E`; stem and word `#F4E9EC`.
- `-ink`: one colour, ink `#1E2A1F`, for print, stamps and embossing.
- `-paper`: one colour, paper `#F3F4EC`, for dark grounds where colour is not possible.

Files:

- `clover-lockup-horizontal-*.svg`: first choice (day, evening, ink, paper).
- `clover-lockup-stacked-*.svg`: cups, bags, square formats. Includes the descriptor “LULE · KAFE · VERË”.
- `clover-wordmark-ink.svg` / `-paper.svg`: when the mark is already nearby.
- `clover-mark-*.svg`: the clover alone.
- `clover-stamp-day.svg` / `-evening.svg`: round stamp for stickers, bouquet wraps and seals.
- `clover-avatar-day.svg` / `-evening.svg`: 200×200 profile images. Swap at 17:00 if the platform allows it.
