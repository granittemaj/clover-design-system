# Icons

24×24 line icons, 1.6px stroke, round caps and joins, single ink `#1E2A1F` (`ink`). Inline the SVG and set `stroke="currentColor"` to recolour, for example on evening grounds.

- `icon-kafe.svg`: coffee. `icon-matcha.svg`: matcha. `icon-vere.svg`: wine.
- `icon-buqete.svg`: bouquets. `icon-porosi.svg`: custom flower orders (lule me porosi).
- `icon-embelsira.svg`: sweets. `icon-meze.svg`: meze boards.
- `icon-dite.svg`: day hours. `icon-mbremje.svg`: evening hours.
- `icon-hapesira.svg`: the space, private events, the floor plan.
