# Tag

One or two words in caps beside a name: “E RE”, “SOT”, “VEGAN”, “PA GLUTEN”.

- Tone follows the subject: `matcha` for coffee and tea, `peony` for flowers, `wine` for the wine list, `candle` for today-only and new things, `neutral` for dietary facts.
- Never more than one tag per item. Write the copy in capitals yourself; keep it under 12 letters.
