# OpenNow

Tells a guest which half of the day the house is in: Ditë (coffee and matcha) or Mbrëmje (wine and meze).

- Put it at the top of the website, the menu screen and the Instagram story template. Pass `part` from the clock: `day` before 17:00, `evening` after.
- `until` is the 24-hour time that half ends. `serving` overrides the default “kafe e matcha” / “verë e meze”.
- The day chip sits on `matcha-soft`; the evening chip is a solid `wine` pill so it holds on either theme.
