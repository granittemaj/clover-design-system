# Button

Pills, verb first, in Albanian sentence case: “Porosit buqetën”, “Rezervo tavolinë”.

- `primary` is the one thing the screen is for, at most once per view. It reads `--primary`, so it is matcha by day and peony by evening without any prop.
- `quiet` is every other action. `ghost` is for inline links such as “Shiko menunë e plotë”.
- `size="sm"` inside cards and menus; the default 44px height everywhere a thumb taps.
- The consumer provides the label and `onClick`. No icons inside buttons; no exclamation marks.
