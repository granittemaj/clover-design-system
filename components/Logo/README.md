# Logo

The logo guidelines page: anatomy of the four-leaf mark, the lockups, clear space, minimum sizes, approved colour pairings and misuse.

- Use the horizontal lockup first; the stacked lockup for square and cylindrical surfaces (cups, bags); the mark alone only where the name is already present or space is under 25mm.
- Clear space is 1x on every side, where x is the height of one leaf. Minimums: lockup 96px / 25mm, wordmark 72px / 18mm, mark 16px / 5mm.
- The leaves never change places or colours: lule top right, kafe bottom right, verë bottom left, ëmbëlsira top left. One-colour versions are for print only.
